# PRD (Product Requirements Document)

## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| 제품명 | DailyNote |
| 한 줄 소개 | 하루 사이클 특화 일기+할일 결합 모바일 앱 |
| 핵심 컨셉 | 아침 계획 → 낮 실행 → 저녁 회고라는 자연스러운 하루 리듬이 제품 구조 |
| 플랫폼 | 모바일 (iOS/Android) - React Native (Expo) |
| 수익 모델 | 없음 (개인 프로젝트/포트폴리오) |

## 2. 핵심 가치

- **하루에 집중**: 과거나 미래가 아닌 "오늘"에 집중하는 구조
- **자연스러운 리듬**: 아침-낮-저녁의 하루 사이클이 앱 사용 흐름과 일치
- **단순함**: 기능 과다 없이 할일+일기+감정 추적 세 가지에 집중
- **부담 없는 기록**: 빈 날은 그냥 비워두기, 프롬프트 없는 자유 작성

## 3. 타겟 사용자

### 페르소나: 성장 지향형 자기계발자

- **연령**: 무관 (20~40대 주 타겟)
- **특성**: 매일 조금씩 나아지고 싶은 사람
- **페인 포인트**: 기록하고 추적할 적절한 도구가 없음
- **일상 패턴**:
  - 아침: 오늘의 목표를 세우고 싶다
  - 낮: 빠르게 메모하고 싶다
  - 저녁: 하루를 돌아보며 기록하고 싶다

## 4. 핵심 기능

### 4.1 오늘의 할일 (Todo)

| 항목 | 내용 |
|------|------|
| 설명 | 오늘만 집중, 미완료 자동 이월, 추가/체크/삭제 |
| Why | 아침에 빠르게 계획을 세우고 낮에 체크하며 성취감을 느끼기 위해 |
| 주요 동작 | 할일 추가, 체크(완료), 삭제, 순서 변경, 미완료 자동 이월 |

### 4.2 일기/회고 작성

| 항목 | 내용 |
|------|------|
| 설명 | 자유 작성 + 음성→텍스트 변환(STT), 마이크 버튼으로 음성 입력 |
| Why | 저녁에 하루를 돌아보며 감정과 경험을 편하게 기록하기 위해 |
| 주요 동작 | 텍스트 입력, 음성 입력(STT), 자동 저장 |

### 4.3 습관/성장 추적

| 항목 | 내용 |
|------|------|
| 설명 | 감정 1~5점 스코어, 감정 흐름 시각화 (주간/월간 그래프) |
| Why | 자신의 감정 패턴을 시각적으로 이해하고 성장 동기를 얻기 위해 |
| 주요 동작 | 감정 점수 입력, 주간/월간 그래프 확인, 연속 기록일(Streak) 확인 |

### 4.4 음성인식 (STT)

| 항목 | 내용 |
|------|------|
| 설명 | 일기 작성 시 마이크 버튼으로 음성 입력, 온디바이스 STT |
| Why | 타이핑이 번거로울 때 편하게 생각을 기록하기 위해 |
| 주요 동작 | 마이크 버튼 탭, 음성 인식 시작/중지, 텍스트 변환 |

## 5. 사용자 스토리

| # | 사용자 | 원하는 것 | 이유 |
|---|--------|-----------|------|
| US-01 | 자기계발자 | 아침에 오늘 할 일을 빠르게 등록 | 하루를 계획적으로 시작할 수 있다 |
| US-02 | 자기계발자 | 할일을 체크하며 진행 상황을 확인 | 성취감을 느낄 수 있다 |
| US-03 | 자기계발자 | 저녁에 하루를 돌아보며 일기를 작성 | 하루의 감정과 경험을 기록할 수 있다 |
| US-04 | 자기계발자 | 음성으로 일기를 작성 | 편하게 생각을 기록할 수 있다 |
| US-05 | 자기계발자 | 감정 흐름을 시각적으로 확인 | 나의 감정 패턴을 이해할 수 있다 |
| US-06 | 자기계발자 | 연속 기록일을 확인 | 꾸준히 기록하는 동기부여를 얻을 수 있다 |
| US-07 | 자기계발자 | 미완료 할일이 자동 이월 | 놓친 할일을 다시 확인할 수 있다 |

## 6. 제약 조건

| 항목 | 내용 |
|------|------|
| 시간 | 개인 프로젝트 (별도 기한 없음) |
| 예산 | 무료 (외부 API 비용 없음) |
| 팀 | 1인 개발 |
| 기술 | React Native (Expo) 기반, 로컬 데이터 저장 (SQLite) |
| 데이터 | 모든 데이터는 디바이스 로컬에 저장, 서버 없음 |

## 7. MVP 범위

### MVP에 포함

- [x] 오늘의 데일리노트 메인 화면 (할일 + 일기 + 감정 스코어 통합)
- [x] 할일 CRUD (추가, 체크, 삭제)
- [x] 미완료 할일 자동 이월
- [x] 일기 자유 작성 및 자동 저장
- [x] 감정 스코어 (1~5점) 입력
- [x] 좌우 스와이프로 날짜 이동
- [x] 통계 화면 (감정 흐름 그래프, 할일 완료율, Streak)
- [x] 설정 화면 (테마, 데이터 백업/복원)
- [x] 음성인식(STT) 일기 입력
- [x] 하단 탭 네비게이션
