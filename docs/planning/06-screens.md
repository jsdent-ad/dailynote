## 2. 화면 상세

### 2.1 screen-01: 오늘의 데일리노트

| 항목 | 내용 |
|------|------|
| ID | screen-01 |
| 화면명 | 오늘의 데일리노트 |
| 경로 | /daily (탭 기본 화면) |
| 설명 | 메인 화면. 날짜+감정스코어+할일리스트+일기작성 통합. 좌우 스와이프로 날짜 이동. |

#### 기능

- 날짜 표시 및 좌우 스와이프 날짜 이동
- 감정 스코어(1~5점) 입력
- 할일 목록 표시 (체크박스)
- 할일 추가 (텍스트 입력)
- 할일 체크 (완료/미완료 토글)
- 할일 삭제 (스와이프 삭제)
- 미완료 할일 자동 이월 표시
- 일기 자유 작성 (텍스트 영역)
- 음성 입력 (마이크 버튼 → STT)
- 자동 저장 (1초 디바운스)

#### 컴포넌트

| 컴포넌트 | 설명 | 위치 |
|----------|------|------|
| DateHeader | 날짜 표시 + 좌우 화살표 | 상단 |
| EmotionScore | 1~5점 감정 스코어 선택 | 날짜 아래 |
| TodoList | 할일 목록 (TodoItem 반복) | 감정 스코어 아래 |
| TodoItem | 개별 할일 (체크박스 + 텍스트) | TodoList 내부 |
| 할일 추가 버튼 | "+" 버튼 또는 입력 필드 | TodoList 하단 |
| DiaryEditor | 자유 텍스트 입력 영역 (멀티라인) | 할일 목록 아래 |
| MicButton | 마이크 버튼 (STT 트리거) | DiaryEditor 우측 하단 |

#### 화면 레이아웃

```
┌─────────────────────────┐

├─────────────────────────┤

│  ┌───────────────────┐  │
│  │ 오늘 하루는       │  │

├─────────────────────────┤
```

## 3. 화면 간 이동 (네비게이션)

### 3.1 하단 탭 네비게이션

```mermaid
flowchart LR
    A[데일리노트] <--> B[통계]
    B <--> C[설정]
    A <--> C
```

| 탭 | 아이콘 | 화면 | 기본 |
|----|--------|------|------|
| 데일리노트 | 노트/캘린더 아이콘 | screen-01 | 기본 탭 (앱 실행 시) |
| 통계 | 차트 아이콘 | screen-02 | - |
| 설정 | 기어 아이콘 | screen-03 | - |

### 3.2 스와이프 네비게이션

- **적용 범위**: screen-01 (오늘의 데일리노트)에서만
- **방향**: 좌우 스와이프
- **동작**: 이전/다음 날짜로 이동 (화면 전환이 아닌 날짜 데이터 전환)
- **애니메이션**: 슬라이드 좌/우 250ms
