# Competitive Analysis (경쟁 분석)

## 1. 경쟁 제품 개요

| # | 제품명 | 카테고리 | 주요 특징 | DailyNote와의 관계 |
|---|--------|----------|-----------|-------------------|
| 1 | Journal it! | 일기/저널 | 다양한 기록 도구, 감정 추적, 습관 추적 | 직접 경쟁 |
| 2 | Structured | 할일/일정 | 타임라인 기반 하루 계획 | 부분 경쟁 (할일) |
| 3 | UpNote | 노트/메모 | 마크다운 노트, 폴더 정리 | 부분 경쟁 (기록) |
| 4 | 데일리노트 (기존) | 일기 | 간단한 일기 작성 | 직접 경쟁 |
| 5 | Notion | 올인원 생산성 | 문서, 데이터베이스, 프로젝트 관리 | 간접 경쟁 |

## 2. 경쟁사별 SWOT 분석

### 2.1 Journal it!

| 구분 | 내용 |
|------|------|
| **Strengths** | - 풍부한 기록 도구 (사진, 오디오, 위치 등) |
| | - 감정 추적 및 통계 기능 |
| | - 습관 추적 기능 내장 |
| | - 예쁜 UI/UX |
| **Weaknesses** | - 기능이 너무 많아 복잡함 |
| | - 할일 관리가 부가 기능 수준 (핵심이 아님) |
| | - "아침-낮-저녁" 하루 사이클 개념 없음 |
| | - 유료 기능이 많음 |
| **Opportunities** | - 기능 과다로 인한 이탈 사용자 흡수 가능 |
| | - 단순함을 원하는 사용자 수요 존재 |
| **Threats** | - 브랜드 인지도가 높음 |
| | - 지속적 업데이트로 기능 확장 중 |

### 2.2 Structured

| 구분 | 내용 |
|------|------|
| **Strengths** | - 직관적인 타임라인 UI |
| | - 시간 기반 할일/일정 관리 |
| | - 캘린더 연동 |
| | - 깔끔한 디자인 |
| **Weaknesses** | - 일기/회고 기능 없음 |
| | - 감정 추적 기능 없음 |
| | - 하루를 돌아보는 기능 부재 |
| | - 성장 추적보다 일정 관리에 집중 |
| **Opportunities** | - 기록/회고 기능을 원하는 Structured 사용자 흡수 |
| | - 할일+일기 결합 니즈 충족 |
| **Threats** | - 할일 관리 UX가 매우 우수 |
| | - Apple Design Award 수상으로 높은 인지도 |

### 2.3 UpNote

| 구분 | 내용 |
|------|------|
| **Strengths** | - 마크다운 지원 |
| | - 폴더/태그 정리 체계 |
| | - 크로스 플랫폼 동기화 |
| | - 저렴한 가격 |
| **Weaknesses** | - 하루 사이클 개념 없음 |
| | - 할일 관리 기능 약함 |
| | - 감정 추적/통계 없음 |
| | - 범용 노트 앱이라 일기 특화 아님 |

| | - 기존 노트 이전 비용이 높음 |

## 4. DailyNote 차별화 포인트

### 4.1 핵심 차별화: "하루 사이클" 구조

기존 경쟁 제품은 할일 또는 일기 중 하나에 치우쳐 있거나, 하루의 흐름(아침-낮-저녁)을 고려하지 않는다. DailyNote는 하루의 자연스러운 리듬을 제품 구조에 반영한다.

| 시간대 | 사용자 행동 | DailyNote 기능 | 경쟁 제품 대응 |
|--------|-----------|----------------|---------------|
| 아침 | 오늘의 계획 수립 | 할일 등록 + 감정 스코어 | 할일 앱은 있지만 감정과 분리 |
| 낮 | 실행 중 체크 | 할일 체크 | 대부분 지원하지만 기록과 분리 |
| 저녁 | 하루 회고 | 일기 작성 + 감정 수정 | 일기 앱은 있지만 할일과 분리 |

### 4.2 차별화 요약

| 차별점 | 설명 |
|--------|------|
| **할일+일기 통합 화면** | 하나의 화면에서 할일과 일기를 함께 관리 (화면 전환 불필요) |
| **미완료 자동 이월** | 어제 못한 일은 오늘로 자동 이동 (놓치지 않음) |
| **감정 스코어 시각화** | 단순 1~5점으로 빠르게 기록, 주간/월간 추이 확인 |
| **음성 일기 입력** | 마이크 버튼으로 편하게 일기 작성 (STT) |
| **압박감 없는 UX** | 빈 날은 그냥 비워두기, 프롬프트 없는 자유 작성 |
| **완전 오프라인** | 로컬 SQLite, 서버 의존 없음, 개인정보 안전 |
| **극도의 단순함** | 3개 화면, 핵심 기능만, 설정 최소화 |

### 4.3 포지셔닝 맵

```
            단순함
              ↑
              │
   DailyNote  │  Structured
   (신규)     │
              │
 ─────────────┼─────────────→ 할일+일기 통합
              │
 데일리노트   │  Journal it!
   (기존)     │
              │
            복잡함

              Notion (왼쪽 하단 - 복잡 + 분리)
              UpNote (중앙 하단 - 범용)
```

### 4.4 경쟁 우위 전략

1. **기능으로 싸우지 않는다**: Journal it!이나 Notion과 기능 수로 경쟁하지 않음
2. **경험으로 차별화한다**: "하루 사이클"이라는 고유한 사용 경험 제공
3. **타겟을 좁힌다**: "매일 기록하며 성장하고 싶은 사람"에게만 집중
4. **진입 장벽을 낮춘다**: 설치 후 바로 사용 가능, 설정 불필요
