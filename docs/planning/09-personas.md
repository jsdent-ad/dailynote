# Personas (사용자 페르소나)

## 페르소나 유형: 성장 지향형 자기계발자

DailyNote의 타겟 사용자는 "매일 조금씩 나아지고 싶은 사람"이다. 연령과 직업은 다양하지만 공통적으로 하루를 계획하고, 실행하고, 돌아보는 습관을 만들고 싶어한다.

---

## 페르소나 1: 김지현 (직장인)

### 기본 정보

| 항목 | 내용 |
|------|------|
| 이름 | 김지현 |
| 나이 | 29세 |
| 직업 | IT 회사 주니어 개발자 (3년차) |
| 거주지 | 서울 |
| 기기 | iPhone 15, 출퇴근 중 주로 사용 |

### 일상 루틴

| 시간 | 활동 |
|------|------|
| 07:00 | 기상, 샤워 |
| 07:30 | 출근 준비, 간단한 아침 |
| 08:00~08:40 | 지하철 출근 (이때 하루 계획을 세우고 싶음) |
| 09:00~18:00 | 업무 (중간중간 개인 할일 생각남) |
| 18:30~19:00 | 퇴근 지하철 |
| 19:30 | 저녁 식사 |
| 20:00~22:00 | 자기계발 (온라인 강의, 사이드 프로젝트) |
| 22:30 | 하루 정리하며 잠들기 전 기록 |

### 페인 포인트

- 아침에 오늘 뭘 해야 하는지 정리가 안 됨
- 업무 중 떠오르는 개인 할일을 적어둘 곳이 마땅치 않음
- 저녁에 "오늘 뭐했지?" 싶을 때가 많음
- Notion에 일기 템플릿을 만들었지만 모바일에서 쓰기 불편해서 포기
- 여러 앱(할일 앱 + 일기 앱)을 쓰다 번거로워서 둘 다 중단
- 감정 기복이 있는데 패턴을 파악하고 싶음

### Jobs-to-be-Done

| Job | 상황 | 기대 결과 |
|-----|------|-----------|
| 아침 계획 | 출근 지하철에서 5분 안에 | 오늘 해야 할 일이 명확해짐 |
| 빠른 메모 | 업무 중 떠오른 할일 | 10초 안에 기록 완료 |
| 저녁 회고 | 잠들기 전 10분 | 오늘을 돌아보고 감정을 정리 |
| 성장 확인 | 주말에 한 주를 돌아볼 때 | 감정 흐름과 할일 완료율로 성장 실감 |

### DailyNote 사용 시나리오

> **아침 8:15 (출근 지하철)**
> 지현은 앱을 열고 오늘의 할일 3개를 빠르게 등록한다. "코드리뷰 완료", "알고리즘 1문제", "운동 30분". 감정 스코어는 3점(보통)으로 체크한다.
>
> **낮 12:30 (점심시간)**
> "코드리뷰 완료"를 체크한다. 점심 먹으면서 떠오른 "세미나 신청"을 할일에 추가한다.
>
> **밤 22:30 (잠들기 전)**
> 남은 할일을 확인하고, 일기를 쓴다. "오늘 코드리뷰에서 좋은 피드백을 받아서 기분이 좋았다. 내일은 알고리즘 2문제 풀어야지." 감정 스코어를 4점(좋음)으로 수정한다.
>
> **주말**
> 통계 탭에서 이번 주 감정 흐름을 확인한다. 수요일만 2점으로 낮았는데, 그날 일기를 다시 보니 야근이 원인이었다. "12일 연속 기록" Streak을 보며 뿌듯해한다.

## 페르소나 2: 이수빈 (대학생)

### 기본 정보

| 항목 | 내용 |
|------|------|
| 이름 | 이수빈 |
| 나이 | 23세 |
| 직업 | 대학교 4학년 (취업 준비 중) |
| 거주지 | 부산 |
| 기기 | Galaxy S24, 항상 소지 |

### 일상 루틴

| 시간 | 활동 |
|------|------|
| 08:00 | 기상 |
| 09:00~12:00 | 수업 또는 도서관 자습 |
| 12:00~13:00 | 점심 |
| 13:00~17:00 | 취업 준비 (자소서, 코딩테스트, 면접 준비) |
| 17:00~18:00 | 운동 |
| 19:00 | 저녁 |
| 20:00~22:00 | 추가 공부 또는 동아리 활동 |
| 23:00 | 하루 정리 |

### 페인 포인트

- 취업 준비 과정이 막막하고 불안함
- 매일 뭘 했는지 기록하지 않으면 "아무것도 안 했다"는 느낌
- 감정 기복이 심한데 원인을 모르겠음
- 복잡한 앱은 설정하다 포기, 단순한 앱을 원함
- 손으로 쓰는 다이어리는 들고 다니기 불편하고 꾸미는 것에 시간이 들어감
- 할일 앱을 쓰지만 미완료 할일이 쌓이면 스트레스

### Jobs-to-be-Done

| Job | 상황 | 기대 결과 |
|-----|------|-----------|
| 할일 관리 | 취업 준비 할일이 많을 때 | 오늘 집중할 것만 보이게 |
| 감정 기록 | 면접 후, 불합격 후 | 감정을 글로 풀어내고 정리 |
| 패턴 발견 | 감정이 자주 흔들릴 때 | 어떤 상황에서 감정이 나빠지는지 파악 |
| 동기부여 | 의욕이 떨어질 때 | 연속 기록일로 "그래도 매일 했다" 확인 |

### DailyNote 사용 시나리오

> **아침 8:30 (침대에서)**
> 수빈은 눈을 뜨자마자 앱을 열고 오늘 할일을 입력한다. "자소서 3번 문항 작성", "코딩테스트 2문제", "영어 단어 50개". 어제 못 끝낸 "포트폴리오 정리"가 자동 이월되어 있다. 감정 스코어 2점.
>
> **낮 15:00 (도서관)**
> "자소서 3번 문항"을 완료 체크. 잠깐 휴식하면서 할일 목록을 보며 남은 것을 확인한다.
>
> **밤 23:00 (자취방)**
> 오늘 할일 4개 중 3개를 완료했다. 일기를 쓰려는데 타이핑이 귀찮아서 마이크 버튼을 누른다. "오늘 자소서를 드디어 완성했다. 솔직히 자신은 없지만 일단 제출했다. 코딩테스트는 한 문제밖에 못 풀었는데 내일 이어서 해야지." 음성이 텍스트로 변환된다. 감정 스코어를 3점으로 변경한다.
>
> **월말**
> 월간 통계를 보니 면접이 있었던 주에 감정 점수가 확 낮아졌다가 합격 통보 후 급상승했다. "나, 결과에 많이 흔들리는구나"라는 걸 객관적으로 인식한다.

## 페르소나 3: 박민수 (프리랜서)

### 기본 정보

| 항목 | 내용 |
|------|------|
| 이름 | 박민수 |
| 나이 | 35세 |
| 직업 | 프리랜서 디자이너 |
| 거주지 | 제주 |
| 기기 | iPhone 16 Pro, iPad 병행 사용 |

### 일상 루틴

| 시간 | 활동 |
|------|------|
| 07:30 | 기상, 명상 10분 |
| 08:00 | 산책 + 아침 식사 |
| 09:00 | 하루 계획 수립 (이때 앱 사용) |
| 09:30~12:30 | 오전 집중 작업 |
| 12:30~14:00 | 점심 + 낮잠 |
| 14:00~18:00 | 오후 작업 (클라이언트 미팅 포함) |
| 18:00~19:00 | 서핑 또는 운동 |
| 19:30 | 저녁 식사 |
| 20:00~21:00 | 독서 또는 개인 프로젝트 |
| 21:30 | 하루 회고 (일기 작성) |
| 22:30 | 취침 |

### 페인 포인트

- 프리랜서라 스스로 일정을 관리해야 하는데 할일이 흩어져 있음
- 명상과 일기를 습관화하고 싶은데 꾸준히 하기 어려움
- 클라이언트 프로젝트 때문에 감정 기복이 있는데 추적하고 싶음
- 기존에 쓰던 Journal it!이 기능이 너무 많아 불필요한 것이 많음
- 자연 속에서 사는 만큼 디지털 도구는 최소한으로 쓰고 싶음
- 가끔 산책 중에 생각을 음성으로 기록하고 싶음

### Jobs-to-be-Done

| Job | 상황 | 기대 결과 |
|-----|------|-----------|
| 하루 구조화 | 아침 명상 후 | 오늘의 우선순위가 명확해짐 |
| 감정 인지 | 클라이언트 미팅 후 | 감정을 기록하고 패턴을 이해 |
| 음성 기록 | 산책 중 아이디어 떠오를 때 | 멈추지 않고 음성으로 기록 |
| 꾸준함 확인 | 루틴이 흐트러질 때 | Streak으로 "이어가고 있다" 확인 |
| 미니멀 도구 | 디지털 과부하 느낄 때 | 하나의 앱으로 기록 통합 |

### DailyNote 사용 시나리오

> **아침 9:00 (명상 후)**
> 민수는 명상을 마치고 앱을 연다. 감정 스코어 4점(좋음). 오늘 할일: "로고 시안 3개 작성", "클라이언트 A 미팅", "포트폴리오 사이트 업데이트". 간단히 입력하고 작업을 시작한다.
>
> **낮 16:00 (미팅 후)**
> 클라이언트 미팅이 잘 끝났다. "클라이언트 A 미팅"을 체크하고, 미팅에서 나온 추가 요청 "배너 디자인 수정"을 할일에 추가한다.
>
> **저녁 18:30 (산책 중)**
> 서핑을 마치고 돌아오는 길에 오늘 작업에 대한 생각이 떠오른다. 앱을 열고 마이크 버튼을 누른다. "오늘 로고 시안을 세 개 만들었는데 두 번째가 가장 마음에 든다. 클라이언트도 비슷하게 생각할 것 같다. 내일 피드백이 기대된다." 음성이 텍스트로 변환되어 일기에 추가된다.
>
> **밤 21:30 (침대에서)**
> 일기를 다시 읽으며 보충한다. 할일 완료 상황을 확인하고, "포트폴리오 사이트 업데이트"는 내일로 미룬다(자동 이월). 감정 스코어를 4점 그대로 유지. "25일 연속 기록 중" -- 한 달 채우는 게 목표다.
