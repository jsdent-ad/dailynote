# User Flow

## 1. 전체 플로우 (Mermaid)

```mermaid
flowchart TD
    A[앱 실행] --> B{첫 실행?}
    B -->|예| C[DB 초기화 + 테이블 생성]
    B -->|아니오| D[오늘 날짜 데이터 로드]
    C --> D

    D --> E[메인 화면: 오늘의 데일리노트]

    E --> F{사용자 행동}

    F -->|할일 추가| G[할일 입력 → 저장]
    G --> E

    F -->|할일 체크| H[완료 상태 토글 → 저장]
    H --> E

    F -->|할일 삭제| I[삭제 확인 → 삭제]
    I --> E

    F -->|일기 작성| J[텍스트 입력 → 자동 저장]
    J --> E

    F -->|마이크 버튼| K[STT 시작 → 음성 인식 → 텍스트 변환]
    K --> J

    F -->|감정 스코어| L[1~5점 선택 → 저장]
    L --> E

    F -->|좌우 스와이프| M[이전/다음 날짜 이동]
    M --> D

    F -->|하단 탭: 통계| N[통계/인사이트 화면]
    N --> O{주간/월간 토글}
    O -->|주간| P[주간 데이터 표시]
    O -->|월간| Q[월간 데이터 표시]
    P --> N
    Q --> N

    F -->|하단 탭: 설정| R[설정 화면]
    R --> S{설정 항목}
    S -->|테마| T[테마 변경]
    S -->|백업| U[데이터 내보내기]
    S -->|복원| V[데이터 가져오기]
    T --> R
    U --> R
    V --> R

    N -->|하단 탭: 데일리노트| E
    R -->|하단 탭: 데일리노트| E
```

## 2. 화면별 플로우

### 2.1 오늘의 데일리노트 (메인 화면)

#### 진입 경로
- 앱 실행 시 기본 진입
- 하단 탭 "데일리노트" 탭
- 다른 화면에서 탭 전환

#### 사용자 행동 플로우

```mermaid
flowchart LR
    subgraph 아침
        A1[앱 실행] --> A2[오늘 할일 등록]
        A2 --> A3[감정 스코어 입력]
    end

    subgraph 낮
        B1[앱 실행] --> B2[할일 체크]
        B2 --> B3[추가 할일 등록]
    end

    subgraph 저녁
        C1[앱 실행] --> C2[남은 할일 확인]
        C2 --> C3[일기 작성]
        C3 --> C4[감정 스코어 수정]
    end

    아침 --> 낮 --> 저녁
```

#### 상세 행동
| 행동 | 트리거 | 결과 | 저장 |
|------|--------|------|------|
| 할일 추가 | 추가 버튼 탭 | 입력 필드 표시 → 텍스트 입력 → 확인 | 즉시 DB 저장 |
| 할일 체크 | 체크박스 탭 | 완료/미완료 토글 | 즉시 DB 저장 |
| 할일 삭제 | 스와이프 또는 길게 누르기 | 삭제 확인 → 삭제 | 즉시 DB 저장 |
| 일기 작성 | 일기 영역 탭 | 키보드 표시 → 텍스트 입력 | 1초 디바운스 자동 저장 |
| 음성 입력 | 마이크 버튼 탭 | STT 시작 → 텍스트 변환 → 일기에 추가 | 변환 완료 후 자동 저장 |
| 감정 입력 | 점수 영역 탭 | 1~5점 선택 | 즉시 DB 저장 |
| 날짜 이동 | 좌우 스와이프 | 이전/다음 날짜 데이터 로드 | - |

#### 이탈 경로
- 하단 탭으로 다른 화면 이동
- 앱 백그라운드/종료 (자동 저장 완료 상태)

### 2.2 통계/인사이트 화면

#### 진입 경로
- 하단 탭 "통계" 탭

#### 사용자 행동 플로우

```mermaid
flowchart TD
    A[통계 화면 진입] --> B[기본: 주간 뷰]
    B --> C[감정 흐름 라인 차트 확인]
    B --> D[할일 완료율 바 차트 확인]
    B --> E[Streak 카운터 확인]
    B --> F{주간/월간 토글}
    F -->|월간| G[월간 뷰로 전환]
    G --> C
    G --> D
    F -->|주간| B
```

#### 이탈 경로
- 하단 탭으로 다른 화면 이동

### 2.3 설정 화면

#### 진입 경로
- 하단 탭 "설정" 탭

#### 사용자 행동 플로우

```mermaid
flowchart TD
    A[설정 화면 진입] --> B{설정 항목 선택}
    B -->|테마| C[테마 선택 모달]
    C --> D[라이트/다크 선택]
    D --> E[즉시 적용]
    B -->|데이터 백업| F[백업 파일 생성]
    F --> G[공유 시트로 내보내기]
    B -->|데이터 복원| H[파일 선택]
    H --> I[복원 확인 다이얼로그]
    I -->|확인| J[데이터 복원 완료]
    I -->|취소| A
    B -->|앱 정보| K[버전 정보 표시]
```

#### 이탈 경로
- 하단 탭으로 다른 화면 이동

## 3. 예외 플로우

### 3.1 미완료 할일 자동 이월

```mermaid
flowchart TD
    A[앱 실행 / 오늘 날짜 진입] --> B{어제 미완료 할일 존재?}
    B -->|예| C[미완료 할일을 오늘로 복사]
    C --> D[오늘 할일 목록에 표시]
    B -->|아니오| D
    D --> E[메인 화면 표시]
```

### 3.2 STT 오류 처리

```mermaid
flowchart TD
    A[마이크 버튼 탭] --> B{마이크 권한 확인}
    B -->|미허용| C[권한 요청 다이얼로그]
    C -->|허용| D[STT 시작]
    C -->|거부| E[토스트: 권한 필요 안내]
    B -->|허용| D
    D --> F{인식 결과}
    F -->|성공| G[텍스트 변환 → 일기에 추가]
    F -->|실패/타임아웃| H[토스트: 다시 시도 안내]
    F -->|네트워크 에러| I[토스트: 오프라인 안내]
```

### 3.3 데이터 복원 충돌

```mermaid
flowchart TD
    A[복원 파일 선택] --> B{파일 유효성 검증}
    B -->|유효| C[기존 데이터 존재?]
    C -->|예| D[경고: 기존 데이터 덮어쓰기 확인]
    D -->|확인| E[데이터 복원 실행]
    D -->|취소| F[복원 취소]
    C -->|아니오| E
    B -->|무효| G[토스트: 올바른 파일이 아닙니다]
    E --> H[성공 토스트 → 메인 화면으로 이동]
```

### 3.4 빈 날짜 처리

- 감정 스코어: 미입력 시 빈 상태로 표시 (기본값 없음)
- 할일: 빈 목록 표시 + "할일을 추가해보세요" 안내 문구
- 일기: 빈 텍스트 영역 표시 (플레이스홀더: "오늘 하루는 어땠나요?")
- 통계 차트: 데이터 없는 날은 빈 포인트로 표시
